# Agentic.nvim / ACP notes

```txt
Agentic.nvim
  -> ACP-compatible provider
  -> provider MCP config
  -> nvim-lsp-mcp or equivalent

```

Keep provider-specific secrets outside this repository.

Use this directory only for repo-local notes, non-secret sample config, and health-check ideas.
