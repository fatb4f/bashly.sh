# Offline references

Place local clones here:

```txt
refs/bashly-framework/
refs/bashly-wiki/
refs/bashly-ai-kit/
```

Suggested clone shape:

```sh
git clone https://github.com/bashly-framework/bashly refs/bashly-framework
git clone <bashly wiki clone url> refs/bashly-wiki
git clone https://github.com/bashly-framework/bashly-ai-kit refs/bashly-ai-kit
```

The repo policy prefers these references over web lookup.
