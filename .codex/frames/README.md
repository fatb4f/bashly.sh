# Frames

Use this directory for durable, low-token state that Codex can read instead of rediscovering the repo on every run.

Suggested files:

- `repo-contract.md`: durable policy and project shape
- `active-project.md`: current Bashly project root and settings
- `validation-report.md`: last known validation state
- `acp-nvim-contract.md`: Agentic.nvim/ACP path and constraints
