# Agentic.nvim Integration

Agentic.nvim is an optional consumer of the Bashly bridge.

It may provide:

- Neovim buffer and selection context
- editor-native diff review
- MCP-backed language intelligence

It is not part of the bridge substrate itself. The bridge substrate remains
repo scripts, headless Neovim, Tree-sitter, `vim.diagnostic`, and MCP tool
contracts.
